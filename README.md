# Spacecraft Structural Analysis and Deployment Dynamics

This repository presents a university project focused on finite element structural analysis and multibody dynamic simulation of spacecraft structures.

## Project overview

The work is divided into two main parts.

The first part focuses on structural analyses performed using Patran and Nastran, including modal analysis, vibro-acoustic response, thermo-elastic analysis, buckling analysis, and reduced-order modeling of spacecraft components.

The second part focuses on the multibody dynamic modeling of a satellite equipped with deployable solar panels using MSC Adams. The model is progressively developed from a rigid-body kinematic representation to a dynamic system with torsional actuators, nonlinear end-stops, flexible bodies, modal analysis, and orbital separation dynamics.

## Main activities

- Static analysis of spacecraft structural components
- Vibro-acoustic response analysis of a parabolic antenna
- Modal analysis in free-free and clamped configurations
- Reduced-order modeling of a solar panel using Craig-Bampton reduction
- Thermo-elastic and buckling analysis of aluminum and composite plates
- Thermo-elastic analysis of a TRAC boom
- Multibody modeling of deployable solar panels
- Dynamic deployment simulation using torsional actuators
- Nonlinear end-stop modeling with BISTOP functions
- Flexible body modeling using MNF files
- Stress analysis of flexible solar panels
- Modal comparison between rigid and flexible models
- Simulation of orbital release and separation dynamics
